- **Symptom:** a follow-up implementer ask exited 1 after 15 s with "run did not start (is the pane … at a shell prompt?)". The reused viewer pane showed zsh `command not found` (127) for `harness-run …`, with one stray Hangul character stuck to the front of it.
- **Cause:** the idle viewer pane's shell input line already held a stray keystroke (probably an IME character typed into the pane after the previous run). `herdr pane run` appends to whatever is on the input line and does not clear it first, so the command was mangled. This is not a busy shell or a cold shell: the prompt was idle.
- **Next time:** clear the input line before sending the command (`herdr pane send-keys` Ctrl-U), or treat exit 127 on a reused pane as safe to retry once.
